# Lanterna Mágica

Slideshow de fotos que roda no navegador. Escolha uma pasta do computador e assista às fotos com transições.

**Abrir:** https://raulfranca.github.io/fotos/

- Cinco temas de transição: álbum de fotos (páginas que viram), polaroides na mesa, Ken Burns, cubo 3D e mosaico.
- Ajuste a duração de cada foto e da transição, a ordem aleatória, a repetição e o enquadramento.
- Tela cheia pelo botão, pela tecla `F` ou com duplo clique. `Espaço` pausa e `←` `→` navegam.
- Aceita fotos HEIC do iPhone: o Safari abre direto e os outros navegadores convertem no próprio computador.
- Os vídeos (.MP4/.MOV), que no iPhone costumam ser a parte animada das Live Photos, ficam de fora.

As fotos são abertas só no seu navegador. Nada é enviado para a internet.

É um único arquivo, `index.html`, sem etapa de build.
